# ecg_machine_learning

## 概要 (Overview)

このプロジェクトは、胸部に貼り付ける16チャンネルECG電極シートから得られるデータに対し、被験者ごとの心臓電気軸を基準とした回転補正を適用するためのプログラム群です。電極シートの物理的な貼り付けズレを補正し、より標準化された心電図データを生成することを目的とします。

処理の中核として、物理16電極から仮想的な9電極を生成し、その仮想電極を基準に電気軸の計算と回転補正を行うことで、安定性と精度を向上させています。

## 処理フロー (Processing Workflow)

データ処理は、以下の3つのスクリプトを順番に実行することで完結します。

1.  **`create_virtual_dataset.py` の実行**
    *   **目的**: 物理16チャンネルの生データセットから、回転補正を適用する前の「仮想9チャンネルデータセット」を作成します。
    *   **入力**: `data/processed/for_best_resample/{subject_name}/` にある物理16chデータセット (`dataset_*.csv`)。
    *   **出力**: `data/processed/virtual_electrode_dataset/{subject_name}/` に、各心拍に対応する仮想9chデータセット (`dataset_*.csv`) を生成します。

2.  **`create_virtual_electrode_axis.py` の実行**
    *   **目的**: 被験者の心臓電気軸を計算します。
    *   **入力**: `data/processed/for_best_resample/{subject_name}/` にある物理16chデータセット。
    *   **処理**:
        1.  全心拍データを平均化し、平均波形を生成します。
        2.  平均波形から仮想9電極の波形を生成します。
        3.  `neurokit2` ライブラリを用いてQRS波を検出し、仮想電極のベクトルから電気軸の角度を計算します。
    *   **出力**: `data/processed/virtual_electrode_dataset/{subject_name}/` に、電気軸の角度やQRS情報を含む `virtual_axis.csv` を生成します。

3.  **`apply_virtual_rotation_correction.py` の実行**
    *   **目的**: 計算された電気軸を用いて、データに回転補正を適用し、最終的なデータセットを生成します。
    *   **入力**:
        1.  `data/processed/for_best_resample/{subject_name}/` にある物理16chデータセット。
        2.  上記2で生成された `virtual_axis.csv`。
    *   **出力**: `data/processed/rotated_datasets/{subject_name}_virtual_rotated/` に、回転補正済みの仮想9chデータセット (`dataset_*.csv`) を生成します。

## 各スクリプトの詳細 (Scripts Details)

### `create_virtual_dataset.py`
- **役割**: 物理16chデータセットを仮想9chデータセットに変換します。各心拍ファイルが個別に変換されます。
- **列の順序**: 出力されるCSVファイルの列は `Time`, `仮想9ch`, `医療12誘導` の順に整列されます。

### `create_virtual_electrode_axis.py`
- **役割**: 被験者一人分のデータ全体から、単一の心臓電気軸を算出します。
- **特徴**:
    - 内部で全心拍を平均化し、ノイズに強い安定した電気軸を計算します。
    - QRS検出には `neurokit2` を使用し、精度を向上させています。
    - 計算結果の `virtual_axis.csv` には、角度だけでなく、計算に使用したQRS波の位置と振幅も含まれます。

### `apply_virtual_rotation_correction.py`
- **役割**: プロジェクトの核心部分。電気軸に基づき、波形に多様性を持たせた回転補正を適用します。
- **補正ロジック (2段階補間)**:
    1. **高解像度マップ作成**: 物理16電極の信号を元に、`griddata` を用いて17x17=289点の高解像度な「電位マップ」を中間生成します。
    2. **最終補間**:
        - 仮想9電極の初期座標（物理グリッド上の絶対座標 (0.5, 2.5) など）を、電気軸の角度とシート中心(1.5, 1.5)を基準に回転させ、最終的な目標座標を計算します。
        - この目標座標における電位を、上記1で作成した**高解像度マップ**から `griddata` で補間して読み取ります。
- **利点**: この2段階補間により、補間元の情報量が増え、補正後の波形がより滑らかで多様性を持つようになります。

## 実行方法 (How to Run)

現在、上記3つのスクリプトは、特定の被験者名でパスがハードコードされています。新しい被験者のデータ処理を行うには、各スクリプトの `if __name__ == "__main__":` ブロック内にある以下の変数を修正する必要があります。

```python
# 例: create_virtual_dataset.py の場合
if __name__ == "__main__":
    ...
    # この値を対象の被験者ディレクトリ名に変更する
    subject_name_full = "asano_0714_0.8s" 
    ...
    main(args)
```

処理したい被験者名（例: `kanda_0807_0.8s`）に合わせてこの `subject_name_full` を変更し、**処理フロー**に記載の順番通りに3つのスクリプトを実行してください。

## 背景: 電極シートの向き問題 (Background: Sensor Sheet Orientation)

本研究で用いる16チャンネル電極シートは、計測時に物理的な貼り付けの向きが一定でないケースが存在します。具体的には、以下の2つのパターンが混在している可能性があります。

1.  **通常 (`normal`)**: `ch_1` がシートの**右下**に位置する。
2.  **反転 (`flipped`)**: `ch_1` がシートの**左上**に位置する。

この向きの違いは、電極番号と物理的な座標のマッピングが異なることを意味し、データ処理において一貫した結果を得るための課題となります。

## 解決策: `orientation` パラメータ (Solution: The `orientation` Parameter)

この問題に対処するため、本プロジェクトの全データ処理スクリプト (`create_virtual_dataset.py`, `create_virtual_electrode_axis.py`, `apply_virtual_rotation_correction.py`) に `orientation` というパラメータが導入されています。

-   **役割**: このパラメータは、処理対象のデータの電極シートの向きが「通常」か「反転」かをスクリプトに伝えます。
-   **設定値**:
    -   `"normal"`: `ch_1` が右下の場合。
    -   `"flipped"`: `ch_1` が左上の場合。

このパラメータは、各スクリプトの座標定義関数 `get_sensor_coordinates` に渡されます。関数内部では、`orientation` の値に応じて、その向きに対応した正しい「チャンネル番号と物理座標のマッピング」を動的に生成します。

これにより、仮想電極の生成から回転補正に至るまで、すべての幾何学的な計算が、実際のデータの向きに即して正しく実行されます。

## 改訂された実行方法 (Revised "How to Run")

新しい被験者のデータ処理、または異なる向きのデータを処理する場合、各スクリプトの `if __name__ == "__main__":` ブロック内にある以下の**2つの変数**を修正する必要があります。

```python
# 例: create_virtual_dataset.py の場合
if __name__ == "__main__":
    ...
    # ##################################################################
    # #############  CONFIGURATION FOR THE SCRIPT RUN  ###############
    # ##################################################################
    subject_name_full = "goto_1219_0.8s"
    args.orientation = "normal"  # <--- "normal" または "flipped" を指定
    # ##################################################################
    ...
    main(args)
```

1.  **`subject_name_full`**: 対象の被験者ディレクトリ名に変更します。
2.  **`args.orientation`**: 計測データの向きに合わせて `"normal"` または `"flipped"` を設定します。

この設定に基づき、各スクリプトは `_{orientation}` というサフィックスを含む一意のディレクトリ（例: `virtual_electrode_dataset/goto_1219_0.8s_normal/`）に結果を保存するため、異なる向きのデータが混在することはありません。

## 研究パイプラインの更新：最大振幅同期と自動方位推定
本プロジェクトの過程で、より高度で頑健なデータ処理パイプラインが構築された。これは、従来の課題であった同期バイアスを解消し、センサーの向きを完全に自動で推定・補正するものである。

### 課題認識
1.  **同期処理のバイアス:** 従来のデータセット(`for_best_resample`)は、特定のチャネル(`ch_1`)を基準に同期されていた。これにより、R波の電位が最大となるチャネルが常に`ch_1`付近に集まるという空間的なバイアスが発生し、正確な方位推定の妨げとなっていた。
2.  **手動の方位指定:** 従来のパイプラインでは、センサーの向き(`normal`/`flipped`)を人間が事前に把握し、パラメータとしてスクリプトに与える必要があった。

### 実行した処理パイプライン
上記課題を解決するために、以下のステップを実行した。

#### ステップ1: バイアスフリーなデータセットの作成
- **目的:** `ch_1`基準の同期バイアスを排除する。
- **処理:**
    1. 既存の `for_best_resample` データセットを読み込む。
    2. 心拍データ（`dataset_*.csv`）ごとに、16チャネルの中で最も振幅（最大値-最小値）が大きいチャネルを動的に特定する。
    3. その最大振幅チャネルのR波ピーク（最大値）が常に心拍セグメントの中心に来るように、全16チャネルのデータを時間シフトさせる。
    4. 5心拍ごとの移動平均を計算し、`moving_ave_datasets` サブディレクトリに保存する。
- **使用スクリプト:** `resync_from_max_amp.py`
- **出力:** 同期バイアスが除去された `for_best_resample_base_max_amp` データセット。

#### ステップ2: センサー方位の自動推定
- **目的:** データの向きを完全に自動で推定する。
- **処理:**
    1. ステップ1で作成したバイアスフリーなデータセット (`for_best_resample_base_max_amp`) を入力とする。
    2. 各被験者の全心拍データを平均化し、代表的な平均心拍波形を生成する。
    3. R波ピークの時点における16チャネルの電位分布（ポテンシャルマップ）を取得する。
    4. 電位が最小のチャネルから最大のチャネルへ向かう「双極子ベクトル」を計算する。
    5. このベクトルの向きから、センサーシートの物理的な向き（正常、上下反転、90度回転など）を自動で分類・推定する。
- **使用スクリプト:** `estimate_orientation.py`
- **出力:** 各被験者の推定方位を記録した `estimated_orientations_max_amp.csv`。

#### ステップ3: 方位補正済みデータセットの作成
- **目的:** ステップ2の推定結果に基づき、全データの向きを統一する。
- **処理:**
    1. `for_best_resample_base_max_amp` データセットと `estimated_orientations_max_amp.csv` を入力とする。
    2. 各被験者の推定方位に応じて、「解剖学的な真の左上」に位置するチャネルを動的に選択する。（例：上下反転なら`ch_16`、90度回転なら`ch_4`など）
    3. そのチャネルを基準（ベースチャネル）として、15チャネルの差分データを再計算する。
- **使用スクリプト:** `apply_auto_orientation_correction.py`
- **出力:** 向きが完全に補正・統一された最終データセット `auto_orientation_corrected_dataset_max_amp`。

#### ステップ4: 比較用データセットの作成
- **目的:** 補正の効果を比較・検証するため。
- **処理:** `for_best_resample_base_max_amp` のデータに対し、向きに関わらず常に `ch_1` を基準とした15チャネル差分データセットを作成。
- **使用スクリプト:** `create_fixed_base_dataset.py`
- **出力:** `15ch_base_ch_1` データセット。

### 今後の研究提案
この方位補正済み高密度ECGデータセットというユニークな成果物に基づき、以下の新規性ある研究が提案される。

1.  **心電位ベクトルの「動的解析」による新たな診断マーカーの探索:**
    - R波ピークだけでなく、心拍全体の電気軸ベクトルの時間的な回転パターン（ベクトル心電図）を解析する。
    - この動的なベクトル軌跡から、心筋虚血や伝導異常などを示す新しい特徴量を抽出し、診断マーカーとしての有用性を検証する。

2.  **「時空間ディープラーニング」による高精度な不整脈分類:**
    - 向きの揃った16チャネルデータを「4x4の動画」として扱い、Conv-LSTMのような時空間モデルを適用する。
    - これにより、従来の波形ベースの分類器では捉えきれなかった、不整脈の発生源や伝播パターンといった空間情報を活用し、分類精度を飛躍的に向上させることを目指す。
